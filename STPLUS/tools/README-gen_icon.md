# STPLUS — generator ikony SmartTube Plus

Tworzy ikonę launchera (320x320, jak oryginał): telewizor z gradientem
róż (góra) -> niebieski (dół) i białym "S+" na ekranie.

Użycie:
    python STPLUS/tools/gen_icon.py [ścieżka_wyjściowa.png]

Domyślnie nadpisuje ikony we wszystkich smakach projektu (main + ststable +
stbeta + stfdroid). Kolory do zmiany w KOLORY poniżej.
